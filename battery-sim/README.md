# XG-BattSim 电池健康仿真 Web

这是微信小程序版的响应式网页版本，可直接部署到 GitHub Pages。

## 功能

- 电池参数与工况录入
- Arrhenius 老化与 Bernardi 生热估算
- SOH、容量保持率、内阻增长、剩余循环和最高温度
- 启发式风险区间提示
- 本地检测历史与打印报告

## 本地运行

该项目没有构建步骤，直接打开 `index.html` 即可，也可以在项目目录运行：

```powershell
python -m http.server 8080
```

## 使用边界

该工具是简化仿真工具，不能替代专业检测设备、BMS 诊断或电池安全认证。实际电池出现鼓包、漏液、异味或异常发热时，应立即停用。
